Student Digital Accountant

Project Introduction

Student Digital Accountant is a C++ console
application designed to help students manage
their personal finances. The program allows
users to input their monthly income, track
cumulative expenses through an interactive
menu, and generate real-time financial reports
that calculate the remaining balance
and provide smart budget warnings.

Step 1: Income Input

The program starts by asking the user to
enter their total monthly income.

Step 2: Interactive Menu

An interactive menu is displayed with three
main options: (1) Add Expense, (2) View
Financial Report, or (3) Exit.

Step 3: Adding Expenses

When selecting Option 1, the user enters an
expense amount, which is dynamically added
to the total expenses.


Step 4: Generating the Report

When selecting Option 2, the system
calculates the remaining balance and
displays a detailed financial report.


Step 5: Smart Budget Warning

If expenses exceed the income, the program
automatically triggers a warning
message; otherwise, it shows a motivational
success message.


Step 6: Exiting the Application

When selecting Option 3, the program
displays a thank-you message and safely
terminates the execution.
